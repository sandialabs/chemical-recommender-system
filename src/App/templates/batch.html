Batch Processing

Process multiple chemical searches efficiently with automated reporting

Input Format

Enter one search per line using this format (all fields required except weights):

query, final_number, thermo_array, include_all_elements, include_specific_elements, disallow_isotopes, substructure_search, number_substructure_search, weights
query: PubChem CID, IUPAC Name, or SMILES
final_number: Number of results (e.g., 30)
thermo_array: [MP, BP, LogP, VP, HL] as True/False
include_all_elements: True/False for all elements
include_specific_elements: Additional elements or None
disallow_isotopes: 0 (allow isotopes) or 1 (disallow isotopes as candidates)
substructure_search: SMARTS pattern or None
number_substructure_search: Min matches or None
weights: [1,1,1,1,1] for similarity weights (optional)

Examples:

6517, 30, [True,True,False,False,False], False, [Si], 1, CCO, 1 Search CID 6517 with 30 results, MP+BP properties, include Silicon, disallow isotopes, require CCO pattern
quinolin-8-ol, 25, [False,False,False,False,True], True, None, 0, None, None, [2,1,1,1,0] Search quinolin-8-ol with Henry's Law, all elements, allow isotopes, weighted structural similarity
