How CRS Works

Streamlined workflow for chemical compound analysis and discovery

1

Input Chemical Query

Enter SMILES, CAS numbers, or chemical names to define your target compound or search criteria.

2

Fingerprint Generation

Convert molecular structures into searchable 2048-bit fingerprints for efficient comparison.

3

Vector Database Search

Perform high-speed similarity searches using Milvus vector database to find candidate compounds.

4

Compute Properties

Calculate thermophysical properties, toxicity, and molecular descriptors using RDKit and Mordred.

5

Results & Visualization

Explore ranked results with interactive visualizations, property comparisons, and detailed analysis.

6

Download Results

Access automated PDF reports, CSV data exports, and comprehensive analysis documentation.
